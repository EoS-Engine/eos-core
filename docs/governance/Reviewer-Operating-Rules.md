# Reviewer Operating Rules

**Document Type:** Operating rule for future reviews. Not architecture. Not a specification.

### Rule 1

Every review starts with STEP-0.

### Rule 2

Architecture Review is prohibited unless Governance §4 allows it.

### Rule 3

Previously closed Work Packages are immutable unless Governance §4 is satisfied.

### Rule 4

Only the active Work Package and regressions introduced by it may be reviewed.

### Rule 5

Engineering Debt is revisited only at its recorded trigger.

### Rule 6

Architecture Gaps remain Governance items unless they become part of the active WP acceptance criteria.

### Rule 7

CodeRabbit is advisory. The Constitution, Roadmap, Specifications, Development Workflow, and Governance remain authoritative.

### Rule 8

Hostile Reviews after WP-018 are Delta-only hostile reviews. They are not project-wide architecture audits.
